# Interactive Playground

Under the `/demo` page, the user has access to a live interactive playground:

1. **Select Left Player**: Choose the first player card.
2. **Select Right Player**: Choose the second player card.
3. **Trigger Operation**: Select **Compose (⊗)** or **Residual (→)**.
4. **Live Execution Console**: Watch the algebraic equation calculate and stream the underlying proof logs directly from the math engine!

Explore the live arena here: [**Go to Playground**](/demo)
